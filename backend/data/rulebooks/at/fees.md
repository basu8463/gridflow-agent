# Austria — Connection Fees (Demo Rulebook)

## Rule AT-FEE-1 — Base fee
Every processed connection application incurs a base handling fee of
**EUR 400**.

## Rule AT-FEE-2 — Capacity surcharge
For requested capacity above **20 kW**, a surcharge of **EUR 150 per kW**
above the threshold applies.

Example: a 30 kW connection = 400 + (30 − 20) × 150 = **EUR 1,900**.

## Rule AT-FEE-3 — Notification-track applications
Notification-only applications incur the base fee only.

## Rule AT-SLA-1 — Processing times
Notification track: confirmation within **14 working days**.
Approval track: decision within **40 working days** of a complete
application.

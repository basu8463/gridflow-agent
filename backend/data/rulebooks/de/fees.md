# Germany — Connection Fees (Demo Rulebook)

## Rule DE-FEE-1 — Base fee
Every processed connection application incurs a base handling fee of
**EUR 500**.

## Rule DE-FEE-2 — Capacity surcharge
For requested capacity above **30 kW**, a surcharge of **EUR 120 per kW**
above the threshold applies.

Example: a 40 kW connection = 500 + (40 − 30) × 120 = **EUR 1,700**.

## Rule DE-FEE-3 — Notification-track applications
Notification-only applications (within notify limits) incur the base fee
only.

## Rule DE-SLA-1 — Processing times
Notification track: confirmation within **10 working days**.
Approval track: decision within **30 working days** of a complete
application.
